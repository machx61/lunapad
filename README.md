# Features:
- 3x3 matrix: 9 keys to handle the best of your tasks
- Rotary encoder: do stuff with just a twist.
- 14 SK6812 Mini LEDs
- QMK firmware

# Working:
- The macropad runs on QMK firmware and the programmed keys can be changed easily using the source files.
